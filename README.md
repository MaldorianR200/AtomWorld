# AtomWorld

Интерактивная образовательная игра для школьников 8–9 классов. Игрок проходит пять станций атомного маршрута, выполняет задания и получает звание **«Покоритель атома»**.

**Играть онлайн:** [maldorianr200.github.io/AtomWorld](https://maldorianr200.github.io/AtomWorld/)

## Станции маршрута

1. **Малыш Атом** — собрать модель атома гелия из протонов, нейтронов и электронов.
2. **АЭС: энергия в деталях** — расположить основные части атомной электростанции по ходу преобразования энергии.
3. **Опасные отходы** — рассортировать отходы по пяти типам опасности.
4. **Чистая вода** — восстановить правильную последовательность этапов очистки воды.
5. **Мир профессий Росатома** — сопоставить специалистов атомной отрасли с их задачами.

Прогресс сохраняется в браузере. После прохождения маршрута можно указать имя и распечатать именной диплом.

## Технологии

- HTML5;
- современный CSS (Grid, Flexbox, адаптивная вёрстка, анимации);
- JavaScript ES Modules;
- Vite для локальной разработки и production-сборки;
- LocalStorage для сохранения прогресса;
- Web Audio API для звуковой обратной связи.

Серверная часть не требуется: приложение полностью работает на frontend.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Локальный адрес с учётом базового пути GitHub Pages: `http://localhost:5173/AtomWorld/`.

Production-сборка:

```bash
npm run build
npm run preview
```

Готовые статические файлы появятся в папке `dist/`.

## Публикация

GitHub Actions автоматически собирает и публикует игру в GitHub Pages после каждого push в ветку `main`. Workflow находится в `.github/workflows/deploy-pages.yml`.

## Структура проекта

```text
AtomWorld/
├── public/                  # Статические ресурсы
├── src/
│   ├── data/                # Контент и данные игры
│   ├── modules/             # Состояние, звук, эффекты
│   ├── stations/            # Логика пяти игровых станций
│   ├── styles/              # Стили приложения
│   └── main.js              # Точка входа
├── index.html
└── package.json
```
